# Commands

All commands are in the Command Palette (++ctrl+shift+p++). The *Where*
column lists the other places a command appears.

## Editing

| Command | Where | Keys |
| --- | --- | --- |
| Open WYSIWYG Editor | editor title bar of a Markdown file | ++ctrl+shift+e++ |
| Open Default Editor | editor title bar of the WYSIWYG editor | ++ctrl+shift+e++ |

## Listening

| Command | Where | Keys |
| --- | --- | --- |
| Read document aloud (Piper) | editor toolbar | ++ctrl+alt+shift+r++ |
| Read Markdown Selection (Piper) | text editor context menu | — |
| Open and listen to document (10 formats) | editor title bar, Explorer context menu | — |
| Listen to the Long-Document Reading Guide (Piper) | reader | — |
| Listening: play | — | ++ctrl+alt+shift+p++ |
| Listening: pause | — | ++ctrl+alt+space++ |
| Listening: stop | — | ++ctrl+alt+shift+s++ |
| Listening: next / previous (passage) | — | ++ctrl+alt+right++ / ++ctrl+alt+left++ |
| Listening: nextHeading / previousHeading | — | ++ctrl+alt+shift+down++ / ++ctrl+alt+shift+up++ |
| Listening: context (where am I) | — | ++ctrl+alt+shift+l++ |
| Listening: back (return from jump) | — | ++ctrl+alt+shift+backspace++ |
| Listening: bookmark | — | ++ctrl+alt+shift+b++ |

The *Listening* keys work only while a reader is open.
