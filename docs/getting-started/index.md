# Getting started

Two short pages take you from nothing to having used every major feature once.

1. [Install](install.md) the extension, either the full offline package or a
   source build.
2. Take [a first tour](first-tour.md): edit a file, listen to it, open the
   documentation mind map and the codebase map, and generate a file from a
   template.

After that, the [tutorials](../tutorials/index.md) cover each feature in
depth, and the [theory of operation](../theory/index.md) explains how each one
works.
