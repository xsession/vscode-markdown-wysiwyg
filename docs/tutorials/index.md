# Tutorials

Each tutorial is a complete task, from opening the right panel to a finished
result. They assume you have [installed](../getting-started/install.md) the
extension and opened a project folder.

| Tutorial | You will… | Time |
| --- | --- | --- |
| [Edit Markdown visually](edit-markdown.md) | write a document with tables, images and code blocks without touching Markdown syntax | 10 min |
| [Listen to a document](listen-to-a-document.md) | listen to a document, navigate it, bookmark and resume | 10 min |
| [Study a long document by ear](study-long-documents.md) | apply a research-based method to a long specification | 30 min |
| [Explore project documentation](explore-documentation.md) | find documents with the tree and mind map, queue them and take a guided tour | 15 min |
| [Learn a codebase with the map](codebase-map.md) | orient yourself in an unfamiliar repository, plan a route and read a CPU profile | 20 min |
| [Convert Markdown with Jinja templates](jinja-templates.md) | generate YAML from a register map, create a template from examples and edit both sides live | 20 min |
| [Keep a table in sync with a config file](table-sync.md) | bind a Markdown table to a JSON file and edit either one | 15 min |
