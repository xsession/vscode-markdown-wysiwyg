# Examples

Sample files you can open in the extension to try each feature.

| Folder | What it is |
| --- | --- |
| `documents/` | the same short guide in ten formats (Markdown, PDF, Word, EPUB, HTML, reStructuredText, …) for trying document import and listening |
| `markdown/` | Markdown samples for the WYSIWYG editor and the offline reader, including Hungarian text in `piper_reader.md` |
| `markdown/formatting/` | smaller files that exercise individual formatting features (headings, lists, tables, …) |

Nothing here is required at runtime; the extension ships its own bundled
assets. These files exist so you can explore features without writing test
content yourself.
