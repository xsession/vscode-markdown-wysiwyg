About this map

The map uses spatial memory to make a codebase easier to learn. The layout is computed only from the folder tree and file sizes, so the same project always produces the same map and locations stay familiar between sessions.

Landmarks. The most-imported files are drawn as towers and remain visible through fog. Entry points are marked with stars.

Routes. The Route tab gives step-by-step directions between two files along import edges. Zooming out shows regions and the highways between them.

Orientation. A trail and a ring on the selected file show where you have been. With fog of war on, only visited areas are revealed.

Walk. The Walk tab visits the landmarks in a fixed order from the entry point outward, a repeatable tour of the architecture.

Runtime. Load a CPU profile (speedscope JSON, .cpuprofile or folded stacks) to see where time is spent and which calls happen without a static import.
